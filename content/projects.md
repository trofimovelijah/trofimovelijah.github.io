### Red Flags Docs - System Analysis

Спецификация платформы выявления юридических рисков "*Красные флажки / до чек-бокса*". Платформа предоставляет механизм определения "красных флажков", содержащихся в различных юридических документов, с которыми приходится иметь дело обычным пользователям. Разработка документации для последующей реализации с использованием различных типов хранилищ и больших языковых моделей. 

**Теги:** SRS, Requirements, C4, RBAC, RAG, ER
